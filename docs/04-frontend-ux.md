# 04 · 프론트엔드 & UX (라우트 · UI · 어드민 · i18n · 테마)

> 상위: `core.md`. 화면·라우트·다국어·다크모드 작업은 이 문서를 따른다.
> 구체적 색·폰트·컴포넌트 스타일은 **디자인 참조 이미지 수령 후** 확정한다(8장).

## 4.1 페이지 / 라우트

```
/                 랜딩 + 입력창
/generate         생성 플로우 (입력 → 객관식 질문 → 결과)
/history          내 생성 기록 (로그인)
/login            Firebase Auth
/settings         언어·테마·계정
/admin            어드민 대시보드 (role=admin)
/admin/users      이용자 관리
/admin/sessions   세션 로그 뷰어
/admin/usage      사용량·원가
```

## 4.2 사용자 메인 플로우

1. 랜딩: "뭘 만들고 싶으세요?" 한 줄 입력창.
2. [1층] 의도 1차 측정 표시: "이렇게 이해했어요 — 맞나요?"
3. [질문] 객관식 카드 최대 3개. 탭 선택. + "기타: 직접 입력".
4. [3·4층] 로딩 → 최종 프롬프트 출력 + **복사 버튼**.
5. (2차) "이 프롬프트로 결과물 바로 보기" → 실행 연동 + Before/After 시연.
6. 비로그인도 체험 가능. 저장/히스토리는 로그인 시.

> UX 핵심: 객관식은 **탭 한 번**으로 끝나게(모바일 우선). 타이핑 최소화.

## 4.3 어드민 대시보드 (`/admin`, role=admin 전용)

기본 위젯:
- 📊 접속 통계: DAU/WAU/MAU, 시간대별 접속, 국가·디바이스 분포
- 👥 이용자: 가입 추이, 최근 로그인, 활성 사용자 목록
- 🧾 세션: 생성 건수, 인기 입력 키워드, 모듈별 분포
- 💰 사용량/원가: LLM 호출 수, 토큰 합계, 추정 비용, 평균 응답시간
- 🔎 세션 상세 뷰어: 입력→질문→답변→산출 추적
- 데이터 소스: `access_logs`, `usage_logs`, `sessions`, `users` (→ `docs/03`)
- 차트 라이브러리: Recharts 또는 Chart.js (가정)

## 4.4 다국어 (i18n)

- 라이브러리: next-intl (가정) — App Router 호환 우선.
- 기본 언어 **ko**, 2차 **en**. 확장: ja, zh … [언어셋 결정 필요].
- 문자열: `messages/{locale}.json` 분리.
- 라우팅: `/[locale]/...` 또는 쿠키 기반 [결정 필요].
- ⚠ **UI 언어 ≠ 생성 프롬프트 언어.** 둘은 별개 변수다.
  유저 locale을 기본값으로 쓰되, 생성 언어(`outputLang`)는 따로 선택 가능하게.
  (`/api/generate` 의 `outputLang` 파라미터 — `docs/02`)

## 4.5 다크 / 라이트 모드

- Tailwind `darkMode: "class"`.
- 헤더에 라이트/다크/시스템 **3-state 토글**.
- 우선순위: 유저 설정(Firestore `theme`) > localStorage > OS 설정.
- SSR 깜빡임 방지: `<html>`에 초기 테마 클래스 주입(next-themes 권장, 가정).
- 색상은 CSS 변수로 정의 → 라이트/다크 양쪽 값 매핑.
  **실제 색상값은 디자인 이미지 수령 후 확정.**

## 4.6 컴포넌트(최소 셋)
- 입력창 / 의도확인 배너 / 객관식 카드 / 로딩 / 프롬프트 출력 블록(복사) / 테마토글 / 언어토글
- 어드민: 통계 카드 / 차트 / 데이터 테이블 / 세션 상세 패널
